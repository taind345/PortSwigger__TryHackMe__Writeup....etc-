### biến 
-biến này nó giống như trong c++ thôi 
```JavaScript
let age = 10
```
-ok cái bên trên có vẻ ko có j đặc sắc.Nhưng *let*  là gì ??
### let
-let này giúp lưu biến khi nó cần thay đổi giá trị
```JavaScript
let ten=Tai
let tuoi=10
// 10 nam sau
ten=Tai
tuoi=20
console.log(tuoi)
```
-> ok cái này ko có gì đặc sắc hehe , next sang cái tiếp theo

### const
-cái thằng này là *hằng số*  , tức là ngược với let là biến 
```JavaScript
const  sua  =gau gau 
let cho1=John
let cho2=mickey
console.log(cho1 ,sua)
```

-*var* là cái cũ của *const*, hiện nay 99% dùng *const* chứ ko còn dùng *var* nữa 



Điều này giúp đọc mã nguồn nhanh hơn.
